# Hello

A small introductory C++ console program that prompts for a first name and prints a personalized greeting.

## Purpose

This repository represents an early programming exercise focused on basic input, output, strings, and program structure.

## Build and Run

```bash
g++ Hello.c -o hello
./hello
```

On Windows with MinGW:

```powershell
g++ Hello.c -o hello.exe
.\hello.exe
```

## Notes

Although the file is named `Hello.c`, it uses C++ headers and syntax. A clearer future filename would be `Hello.cpp`.
